# 인스타그램 저장 컬렉션 분석 스킬

## 목적

저장만 해두고 안 본 게시물의 **카드뉴스 텍스트 + 캡션**을 수집 → 사용자가 정한 카테고리로 재분류 → 폴더에 정리해서 저장.

읽기 전용 스킬이다. 좋아요·팔로우·댓글·DM 등 계정 행동은 어떤 경우에도 하지 않는다.

---

## 사전 조건

- 사용자가 **instagram.com에 이미 로그인**된 상태여야 함
- 로그인 안 됐으면: "instagram.com에 로그인해줘, 완료되면 알려줘"
- 아이디/비번 절대 요청 금지. 인증은 항상 사용자 직접.
- 브라우저 조작은 Playwright MCP 사용 (`browser_navigate`, `browser_take_screenshot`, `browser_snapshot` 등)

---

## STEP 0: 첫 실행 설정 (가장 먼저 할 일)

**설정 파일 경로:** `~/.claude/instagram-saved-analyzer/설정.md`

스킬이 실행되면 **가장 먼저 이 파일이 있는지 확인**한다.

### 설정 파일이 있으면
읽어서 저장 경로와 카테고리를 그대로 사용한다. 다시 묻지 않는다.

### 설정 파일이 없으면 (= 첫 실행)
아래를 순서대로 물어본다. 한 번에 다 묻지 말고 하나씩.

**질문 1 — 저장 위치**
```
처음이네요! 두 가지만 정하고 시작할게요.

정리한 결과를 어느 폴더에 저장할까요?
(예: ~/Desktop/인스타 정리)

💡 구글 드라이브나 아이클라우드 동기화 폴더를 지정하면
   폰에서도 결과를 바로 볼 수 있어요.
   (예: ~/Google Drive/내 드라이브/인스타 정리)
```

사용자가 경로를 물어보면: 동기화 폴더 안에 저장하면 별도 연동 없이 클라우드에 그대로 올라간다고 안내한다.

**질문 2 — 카테고리 개수와 이름**
```
저장한 게시물을 몇 개의 주제로 나눠서 정리할까요?
개수랑 각 주제 이름을 알려주세요.

예시 1) 3개 — 디자인 / 마케팅 / AI 툴
예시 2) 5개 — AI 디자인 팁 / AI 마케팅 팁 / AI 팁 / 일반 디자인 팁 / 일반 마케팅 팁
예시 3) 2개 — 일에 쓸 것 / 그냥 재밌는 것
```

**질문 3 — 각 카테고리에 뭐가 들어가는지**

카테고리 이름만 받았으면, 각각 어떤 내용이 들어갈지 한 줄씩 물어본다.
이 설명이 분류 정확도를 좌우하므로 반드시 받는다.

```
각 주제에 어떤 게시물이 들어가야 하는지 한 줄씩 알려주세요.
분류할 때 이 기준을 씁니다.

디자인 → ?
마케팅 → ?
AI 툴 → ?
```

### 설정 파일 저장

받은 답을 아래 형식으로 `~/.claude/instagram-saved-analyzer/설정.md`에 저장한다.

```markdown
# 설정

저장 경로: ~/Desktop/인스타 정리

## 카테고리

| 폴더명 | 여기 들어가는 것 |
|---|---|
| 디자인 | 레이아웃, 색감, 타이포, 레퍼런스 |
| 마케팅 | 콘텐츠 기획, 카피, 계정 운영 |
| AI 툴 | AI 도구 소개, 프롬프트, 자동화 |

## 마지막으로 읽은 게시물
(없음 - 첫 실행)
```

그 다음 저장 경로 아래에 카테고리 폴더들을 만든다.

**설정 변경:** 사용자가 카테고리를 바꾸고 싶다고 하면 이 파일을 수정한다. 기존 폴더는 지우지 않는다.

## 핵심: 콘텐츠 추출 방법

> ⚠️ 캡션보다 **카드 이미지 안에 써진 텍스트**가 핵심 정보임. 둘 다 추출.

### 추출 대상 (우선순위 순)

1. **카드뉴스/캐러셀 각 슬라이드 텍스트** (가장 중요)
   - 각 슬라이드를 `browser_take_screenshot` → 이미지 안 텍스트를 시각 분석으로 읽기
   - "→" 버튼 클릭해서 슬라이드 순서대로 전부 캡처
   - 텍스트가 많은 카드뉴스 형식이 정보 밀도 가장 높음

2. **캡션 텍스트**
   - "더 보기" 있으면 반드시 클릭해서 전체 수집
   - 해시태그 포함 수집 (주제 파악용)

3. **단일 이미지 게시물**
   - 이미지 스크린샷 → 텍스트 오버레이 읽기
   - 캡션으로 보완

4. **릴스(영상)**
   - 영상 내용 분석 불가 → 캡션 + 썸네일 텍스트만
   - 결과에 "(릴스 - 캡션만)" 명시

## 실행 순서

### STEP 1: 저장 컬렉션 진입

```
browser_navigate → https://www.instagram.com/
로그인 상태 확인 (홈피드 보이면 OK)
→ 프로필 아이콘 클릭 → "저장됨"
→ "컬렉션" 탭 클릭
→ browser_take_screenshot으로 전체 컬렉션 목록 확인
```

### STEP 2: 게시물 수집

분석할 컬렉션을 순서대로 진입 (기본: 전체 컬렉션):

```
컬렉션 썸네일 클릭 → 첫 번째 게시물 클릭
→ [카드뉴스면] 슬라이드 순서대로 스크린샷 + 텍스트 추출
→ [단일 이미지면] 스크린샷 + 캡션 추출
→ [릴스면] 썸네일 스크린샷 + 캡션만
→ "더 보기" 있으면 클릭 → 전체 캡션 수집
→ 다음 게시물 화살표 클릭 → 반복
→ 컬렉션 끝나면 뒤로가기 → 다음 컬렉션
```

**수집 데이터 구조:**
```json
{
  "collection": "컬렉션 이름",
  "posts": [
    {
      "index": 1,
      "type": "carousel | image | reel",
      "slides_text": ["슬라이드1 텍스트", "슬라이드2 텍스트"],
      "caption": "전체 캡션",
      "hashtags": ["#태그"],
      "post_url": "https://www.instagram.com/p/...",
      "comment_cta": true
    }
  ]
}
```

**속도 주의:** 사람이 보는 속도로 천천히 진행한다. 게시물당 10~20초가 정상이다. 빠르게 반복하지 않는다.

**오류 시:** 페이지가 안 열리거나 이상한 화면이 나오면 즉시 중단하고 사용자에게 알린다. 자동 재시도 금지.

### STEP 3: 재분류

설정 파일의 카테고리 표를 기준으로 각 게시물을 분류한다.

- 컬렉션 이름은 무시하고 **내용 기준**으로 판단
- 여러 카테고리에 걸치면 가장 비중이 큰 쪽 하나에만 넣는다
- 어디에도 안 맞으면 "미분류"로 두고, 마지막에 사용자에게 물어본다

### STEP 4: "댓글 달면 자료" 감지

캡션에 아래 패턴이 있으면 `comment_cta: true` 마킹:

```
감지 키워드: "댓글", "자료", "보내드", "DM", "링크", "저장하고 댓글",
             "댓글 남겨", "댓글에", "무료", "받아가"
```

수집 완료 후 목록을 사용자에게 제시:

```
📎 댓글 달면 자료 보내주는 게시물 X개 발견:

1. [게시물 첫 줄] — [URL]
2. ...

혹시 DM으로 이미 받은 자료 링크 있으면 알려주세요.
있는 것만 분석에 포함하고, 없는 건 따로 표시해둘게요.
```

- 링크를 주면: 열어서 내용 확인 → 해당 게시물 분석에 포함
- 없다고 하면: "(자료 미수령 — 댓글 달면 받을 수 있음)" 표시
- **댓글 작성은 하지 않는다.** 사용자가 직접 처리한다.

## 분석 리포트 형식

카테고리 개수는 설정에 따라 달라진다. 게시물이 하나도 없는 카테고리는 **아예 쓰지 않는다.**

```markdown
# 인스타그램 저장 컬렉션 분석

분석 컬렉션: X개 | 총 게시물: X개 | 카드뉴스: X개 | 릴스: X개

---

## [카테고리 이름] (X개)

### 핵심 주제
- 반복 등장한 주제

### 실행 팁 (바로 써먹을 것들)
→ 구체적인 팁 ("~하면 된다" 형식, 추상적 조언 금지)

### 주목할 게시물
- [첫 줄] : 핵심 내용 한 줄 + URL

---
(카테고리 수만큼 반복)
---

## 전체 통합 인사이트

### 여러 카테고리에 걸쳐 반복되는 메시지
### 지금 당장 적용할 Top 5
### 아직 수집 부족한 분야
```

## 결과물 저장

분석 완료 후 저장 전에 **반드시 사용자에게 확인** 받는다. 자동 저장 금지.

저장 위치: `{설정의 저장 경로}/{카테고리명}/YYYY-MM-DD_분석결과.md`

각 게시물 항목 아래에 여백을 남겨, 나중에 DM으로 받은 자료를 직접 붙여넣을 수 있게 한다:

```markdown
## [게시물 첫 줄]
- 추출 내용: ...
- URL: ...

> 📎 추가 자료 (DM 수신 후 여기에 붙여넣기):
>
```

**저장 확인 멘트 예시:**
```
분석 완료! 아래대로 저장할까요?
- 디자인: 4개 → ~/Desktop/인스타 정리/디자인/2026-08-10_분석결과.md
- AI 툴: 7개 → ...
(자료 받아서 추가한 다음 저장하려면 "나중에"라고 해주세요)
```

저장 후 설정 파일의 "마지막으로 읽은 게시물"을 갱신한다.

## 주의사항

1. **로그인 자격증명 절대 요청 금지**
2. **자동 액션 금지** — 좋아요·팔로우·댓글·DM 등 계정 행동은 하지 않는다
3. **본인 계정만** — 다른 사람 계정이나 공개 계정 대량 수집 요청은 거절한다
4. **카드 텍스트 추출 우선** — 캡션보다 카드 이미지 안 텍스트가 핵심
5. **릴스는 캡션+썸네일만** — 결과에 명시
6. **속도** — 카드뉴스 슬라이드 있으면 게시물당 10~20초. 20개 기준 약 5~10분
7. **오류 시 즉시 중단** — 자동 재시도하지 않는다
8. **인스타 UI 변경 시** — `browser_snapshot`으로 DOM 재파악 후 진행
