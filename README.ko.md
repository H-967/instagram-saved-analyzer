# instagram-saved-analyzer

[English](README.md) · **한국어**

인스타그램에 저장만 해두고 안 본 게시물을, 대신 읽고 폴더별로 정리해주는 Claude 스킬입니다.

3주간 매일 직접 쓰면서 다듬은 스킬을 공개합니다.

> **클로드 코드가 필요합니다.** 브라우저를 조작하는 스킬이라 설치 과정에 터미널이 필요해요. 맥과 윈도우 둘 다 되는 구조지만, 지금까지 확인된 건 맥입니다.

---

## 뭘 하나요

- 저장한 게시물을 열어서 **카드뉴스 슬라이드 안에 적힌 글자까지** 읽습니다 (캡션만 보지 않습니다)
- **내가 정한 주제**로 다시 분류합니다 (3개든 5개든, 이름도 직접 정합니다)
- 주제별 폴더에 날짜별 `.md` 파일로 저장합니다
- 댓글 달면 자료 준다는 게시물은 따로 모아서, 받은 링크가 있는지 먼저 물어봅니다

읽기 전용입니다. 좋아요, 팔로우, 댓글, DM 같은 계정 행동은 하지 않습니다.

---

## 설치

### 1. 스킬 받기 (제일 쉬운 방법)

[`SKILL.md`](plugins/instagram-saved-analyzer/skills/instagram-saved-analyzer/SKILL.md) 파일을 받아서, 클로드한테 그 파일을 주면서 이렇게 말하세요.

```
이 스킬 내 스킬 폴더에 넣어줘
```

끝입니다. 클로드가 알아서 `~/.claude/skills/instagram-saved-analyzer/SKILL.md` 위치에 넣어줍니다.

<details>
<summary>플러그인으로 설치하려면 (클로드 코드 터미널에서만)</summary>

```
/plugin marketplace add H-967/instagram-saved-analyzer
/plugin install instagram-saved-analyzer@h967-skills
```

</details>

### 2. Playwright MCP 설치 (브라우저를 열기 위해 필요합니다)

터미널에 아래 한 줄을 붙여넣으세요. Node.js 18 이상이 필요합니다.

```
claude mcp add playwright npx @playwright/mcp@latest
```

Claude Code에서 `/mcp` 를 쳤을 때 playwright가 connected로 보이면 성공입니다.

### 3. 인스타그램 로그인

크롬에서 인스타그램에 로그인해두세요. 아이디와 비밀번호는 묻지도, 저장하지도 않습니다. 로그인은 항상 본인이 직접 합니다.

## 사용법

### 첫 실행 — 폴더 설정하기

Claude Code에서 이렇게 부르세요.

```
저장한 거 읽어줘
```

처음이면 세 가지를 물어봅니다.

**1) 결과를 어디에 저장할지**

```
~/Desktop/인스타 정리
```

💡 **구글 드라이브나 아이클라우드 동기화 폴더를 지정하면 폰에서도 바로 볼 수 있습니다.** 별도 연동 설정은 필요 없습니다. 동기화 폴더에 파일이 저장되면 알아서 올라갑니다.

```
~/Google Drive/내 드라이브/인스타 정리
```

**2) 몇 개의 주제로 나눌지, 이름은 뭘로 할지**

```
3개요. 디자인 / 마케팅 / AI 툴
```

개수는 자유입니다. 2개도 되고 6개도 됩니다.

**3) 각 주제에 뭐가 들어가는지**

```
디자인 → 레이아웃, 색감, 타이포, 레퍼런스
마케팅 → 콘텐츠 기획, 카피, 계정 운영
AI 툴 → AI 도구 소개, 프롬프트, 자동화
```

이 설명이 분류 기준이 됩니다. 대충 쓰면 분류도 대충 됩니다.

여기까지 하면 설정이 `~/.claude/instagram-saved-analyzer/설정.md` 에 저장됩니다. **다음부터는 안 물어봅니다.**

### 두 번째부터

```
저장한 거 읽어줘
```

이 한 줄이면 끝입니다. 특정 컬렉션만 볼 수도 있습니다.

```
ai 팁 컬렉션만 분석해줘
```

### 주제를 바꾸고 싶으면

```
정리 주제 바꾸고 싶어
```

설정 파일을 고쳐줍니다. 기존 폴더는 지우지 않습니다.

### 걸리는 시간

게시물 20개 기준으로 5~10분쯤 걸립니다. 카드뉴스는 슬라이드를 한 장씩 넘겨 읽기 때문에 느립니다. 브라우저 창이 저절로 움직이는 게 정상입니다.

## 알고 쓰세요

이 스킬은 브라우저를 조작해서 본인 계정의 저장 컬렉션을 읽습니다. 인스타그램 이용약관은 사전 허가 없는 자동화된 접근을 제한하고 있어, 이 방식은 약관상 자동 접근에 해당할 수 있습니다.

- 저는 제 계정으로 3주간 하루 한 번 사용했고, 계정 관련 문제는 없었습니다
- 다만 계정 제한 가능성이 완전히 0은 아니며, **계정 관련 책임은 사용하는 분에게 있습니다**
- 짧은 시간에 여러 번 반복 실행하지 마세요. 하루 한 번 정도가 적당합니다
- 실행 중 오류가 나면 즉시 멈추고, 바로 다시 시도하지 마세요

다음 기능은 의도적으로 넣지 않았고, 앞으로도 넣지 않습니다.

- 좋아요 / 팔로우 / 댓글 / DM 등 계정 행동 자동화
- 로그인 자동화, 비밀번호 저장
- 다른 사람 계정이나 공개 계정 대량 수집
- 감지 우회 로직
